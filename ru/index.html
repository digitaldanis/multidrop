AirDrop, Quick Share, LocalSend и AirPlay в одном приложении – для Windows и Linux

Ваш ПК появляется в меню «Поделиться» любого телефона рядом. iPhone говорят на AirDrop, Android и Samsung – на Quick Share, остальные используют LocalSend. MultiDrop говорит на всех сразу.

Скачать для Windows Установить в Linux ★ Исходный код на GitHub

Что умеет MultiDrop

  • Quick Share / Nearby Share в Windows и Linux – телефоны Android и Samsung отправляют на ПК из меню «Поделиться», без приложений
  • AirDrop в Linux – отправка и приём с iPhone, iPad и Mac (поддерживаемая Wi-Fi-карта)
  • С iPhone на Windows – через бесплатное приложение LocalSend или по QR-коду в браузере, без приложения
  • AirPlay – трансляция экрана Windows или Linux на Apple TV, звук ПК на HomePod и Sonos
  • Приватно – напрямую между устройствами в вашей сети Wi-Fi, с шифрованием, без сервера и аккаунта

Ubuntu и Debian

curl -fsSL https://digitaldanis.github.io/multidrop/multidrop-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/multidrop-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/multidrop-archive-keyring.gpg] https://digitaldanis.github.io/multidrop stable main" \
  | sudo tee /etc/apt/sources.list.d/multidrop.list
sudo apt update && sudo apt install multidrop

Вопросы

Есть ли AirDrop для Windows?

Радиоканал AirDrop от Apple (AWDL) не работает с Wi-Fi-драйверами Windows. MultiDrop закрывает остальное: iPhone отправляет через LocalSend или QR-код в браузере, Android и Samsung – через Quick Share, плюс трансляция экрана по AirPlay.

Есть ли AirDrop для Linux?

Да. MultiDrop отправляет и принимает по AirDrop с iPhone, iPad и Mac в Linux, если Wi-Fi-карта это поддерживает (например, MediaTek MT7925).

Как передать файлы с iPhone на ПК без кабеля?

Запустите MultiDrop на ПК и отправьте из бесплатного приложения LocalSend или отсканируйте камерой QR-код загрузки через браузер.

Можно ли пользоваться Quick Share на ПК?

Да. MultiDrop появляется в меню Quick Share телефонов Android и Samsung в Windows и Linux, без аккаунта Google.

MultiDrop бесплатный и приватный?

Да. Открытый код (GPL-3.0), без сервера и аккаунта – файлы идут напрямую между вашими устройствами.
