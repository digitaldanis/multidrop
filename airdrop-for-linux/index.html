AirDrop for Linux

MultiDrop puts your Linux PC into the AirDrop list of iPhones, iPads and Macs nearby – in both directions, with no app on the Apple device.

Install on Linux Download for Windows ★ Source code on GitHub

How it works

AirDrop runs over Apple Wireless Direct Link (AWDL), a Wi-Fi link between devices. MultiDrop uses omdrop-owl, an open implementation of AWDL, and speaks the AirDrop protocol on top of it. Your PC then appears in the iPhone's share sheet like a Mac.

What you need

A Wi-Fi card that omdrop-owl supports: tested with MediaTek MT7925; Intel cards work in exclusive mode. Without a supported card, iPhones can still send to Linux with the free LocalSend app or download files from the PC by scanning a QR code.

Wi-Fi channel

AWDL lives on channel 6, 44 or 149. If your Wi-Fi network is on another channel, MultiDrop briefly moves to the same network on one of those channels and moves back afterwards. No router changes are needed.

How to set it up

  1. Install MultiDrop from the APT repository (Ubuntu 24.04+, Debian 13+) or with tools/install-desktop.sh on Fedora, Arch and openSUSE.
  2. Build and install omdrop-owl once: tools/build-omdrop-owl.sh, then install the .deb it produces.
  3. Turn on AirDrop in the MultiDrop menu in the top bar.
  4. On the iPhone, tap Share → AirDrop and pick your PC. Accept the transfer on the PC.

Questions

Does AirDrop on Linux need a Mac or an Apple account?

No. MultiDrop talks to the iPhone directly. Set AirDrop on the iPhone to Everyone for 10 minutes so it sees the PC.

Which Linux distributions work?

Ubuntu 24.04+ and Debian 13+ through the APT repository, and Fedora, Arch, openSUSE and others with the installer script. It needs Python 3.11+, GTK 4 and libadwaita.

Can I send from Linux to an iPhone?

Yes. Drop files on the iPhone in the MultiDrop window, or right-click files in the file manager → Send with MultiDrop.
