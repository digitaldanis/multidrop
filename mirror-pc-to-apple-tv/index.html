AirPlay from Windows and Linux to an Apple TV

Show your PC screen on an Apple TV or AirPlay TV, or play the PC's sound on a HomePod or Sonos speaker – from Windows or Linux.

Download for Windows Install on Linux ★ Source code on GitHub

Screen mirroring

MultiDrop uses doubletake as its AirPlay mirroring engine. It works with Apple TV, Macs and AirPlay TVs from Samsung, LG, Roku and others. The first time, enter the code the TV shows. Tested with real Apple TVs.

Audio

Play this PC's sound on a speaker sends your PC audio to AirPlay speakers such as HomePod, Sonos and Apple TV. Receivers that require a password for AirPlay 1 streams are marked as not supported.

How to set it up

  1. Windows: install MultiDrop-Setup.exe (the portable .exe has no mirroring). Linux: install MultiDrop and run multidrop-fetch-doubletake once.
  2. Windows: click Show this PC's screen on a TV. Linux: open Mirror screen in the top bar menu.
  3. Pick the TV and enter the code it shows the first time.

Questions

Does it need the same network?

Yes. The PC and the Apple TV must be on the same local network.
