MultiDrop – the AirDrop alternative for Linux and Windows

iPhones speak AirDrop, Android and Samsung phones speak Quick Share, and the rest use LocalSend. MultiDrop speaks all of them, so your PC shows up in the share menu of every phone nearby. Free, open source, no cloud, no account.

Download for Windows and Linux · Source on GitHub

Install on Ubuntu / Debian (APT)

Ubuntu 24.04+ and Debian 13+.

curl -fsSL https://digitaldanis.github.io/multidrop/multidrop-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/multidrop-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/multidrop-archive-keyring.gpg] https://digitaldanis.github.io/multidrop stable main" \
  | sudo tee /etc/apt/sources.list.d/multidrop.list
sudo apt update
sudo apt install multidrop

Features

  • AirDrop for Linux – send and receive with iPhone, iPad and Mac
  • Quick Share for PC – Android and Samsung phones, no extra app
  • LocalSend compatible, plus browser download with QR code and PIN for any phone
  • AirPlay screen mirroring and audio streaming
