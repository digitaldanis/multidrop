AirDrop、Quick Share、LocalSend 和 AirPlay，一个应用全搞定 —— 支持 Windows 和 Linux

你的电脑会出现在身边每部手机的分享菜单里。iPhone 用 AirDrop，安卓和三星用 Quick Share，其他手机用 LocalSend —— MultiDrop 同时支持它们全部。

下载 Windows 版 在 Linux 上安装 ★ GitHub 源代码

MultiDrop 能做什么

  • Windows 和 Linux 上的 Quick Share / 附近分享 —— 安卓和三星手机直接从分享菜单发送到电脑，无需安装应用
  • Linux 上的 AirDrop —— 与 iPhone、iPad 和 Mac 互传（需支持的无线网卡）
  • iPhone 传到 Windows —— 使用免费的 LocalSend 应用，或在浏览器中扫描二维码，无需应用
  • AirPlay 投屏 —— 把 Windows 或 Linux 屏幕镜像到 Apple TV，把电脑声音播放到 HomePod 和 Sonos
  • 隐私安全 —— 设备之间通过 Wi-Fi 直连并加密，没有服务器，无需账号

Ubuntu 和 Debian

curl -fsSL https://digitaldanis.github.io/multidrop/multidrop-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/multidrop-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/multidrop-archive-keyring.gpg] https://digitaldanis.github.io/multidrop stable main" \
  | sudo tee /etc/apt/sources.list.d/multidrop.list
sudo apt update && sudo apt install multidrop

常见问题

Windows 上有 AirDrop 吗？

苹果 AirDrop 使用的无线技术（AWDL）无法在 Windows 网卡驱动上运行。MultiDrop 解决其余一切：iPhone 通过 LocalSend 或浏览器二维码发送，安卓和三星使用 Quick Share，另外还能 AirPlay 投屏。

Linux 上有 AirDrop 吗？

有。只要无线网卡支持（例如 MediaTek MT7925），MultiDrop 就能在 Linux 上通过 AirDrop 与 iPhone、iPad 和 Mac 互传文件。

如何不用数据线把 iPhone 的文件传到电脑？

在电脑上打开 MultiDrop，然后在 iPhone 上用免费的 LocalSend 发送，或用相机扫描浏览器下载的二维码。

电脑能用 Quick Share 吗？

可以。在 Windows 和 Linux 上，MultiDrop 会出现在安卓和三星手机的 Quick Share 菜单中，无需 Google 账号。

MultiDrop 免费且保护隐私吗？

是的。开源（GPL-3.0），没有服务器也无需账号，文件直接在你的设备之间传输。

AirDrop 和 AirPlay 是 Apple Inc. 的商标，Quick Share 是 Google LLC 和三星电子的商标。MultiDrop 是独立的开源项目。
