AirDrop, Quick Share, LocalSend, dan AirPlay dalam satu aplikasi – untuk Windows dan Linux

PC kamu muncul di menu berbagi setiap ponsel di sekitar. iPhone memakai AirDrop, Android dan Samsung memakai Quick Share, sisanya LocalSend – MultiDrop mendukung semuanya sekaligus.

Unduh untuk Windows Pasang di Linux ★ Kode sumber di GitHub

Yang bisa dilakukan MultiDrop

  • Quick Share / Nearby Share di Windows dan Linux – ponsel Android dan Samsung mengirim ke PC dari menu berbagi, tanpa aplikasi
  • AirDrop di Linux – kirim dan terima dengan iPhone, iPad, dan Mac (kartu Wi-Fi yang didukung)
  • Dari iPhone ke Windows – dengan aplikasi gratis LocalSend atau memindai kode QR di browser, tanpa aplikasi
  • AirPlay – mirror layar Windows atau Linux ke Apple TV, putar suara PC di HomePod dan Sonos
  • Privat – langsung antar perangkat di Wi-Fi kamu, terenkripsi, tanpa server dan akun

Ubuntu dan Debian

curl -fsSL https://digitaldanis.github.io/multidrop/multidrop-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/multidrop-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/multidrop-archive-keyring.gpg] https://digitaldanis.github.io/multidrop stable main" \
  | sudo tee /etc/apt/sources.list.d/multidrop.list
sudo apt update && sudo apt install multidrop

Pertanyaan

Apakah ada AirDrop untuk Windows?

Radio AirDrop milik Apple (AWDL) tidak berjalan di driver Wi-Fi Windows. MultiDrop menangani sisanya: iPhone mengirim lewat LocalSend atau kode QR di browser, Android dan Samsung lewat Quick Share, plus screen mirroring AirPlay.

Apakah ada AirDrop untuk Linux?

Ya. MultiDrop mengirim dan menerima lewat AirDrop dengan iPhone, iPad, dan Mac di Linux jika kartu Wi-Fi mendukung (misalnya MediaTek MT7925).

Bagaimana memindahkan file dari iPhone ke PC tanpa kabel?

Jalankan MultiDrop di PC, lalu kirim dari aplikasi gratis LocalSend atau pindai kode QR unduhan browser dengan kamera.

Bisakah saya memakai Quick Share di PC?

Bisa. MultiDrop muncul di menu Quick Share ponsel Android dan Samsung di Windows dan Linux, tanpa akun Google.

Apakah MultiDrop gratis dan privat?

Ya. Open source (GPL-3.0), tanpa server dan akun; file berpindah langsung antar perangkatmu.

AirDrop dan AirPlay adalah merek dagang Apple Inc., Quick Share milik Google LLC dan Samsung Electronics. MultiDrop adalah proyek open source independen.
