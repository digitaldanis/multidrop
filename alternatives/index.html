MultiDrop compared with other file sharing apps

MultiDrop builds on several great open-source projects. Here is what each one does, so you can pick the right tool.

Download for Windows Install on Linux ★ Source code on GitHub

LocalSend

Cross-platform app for every system. Both devices need the LocalSend app. MultiDrop speaks LocalSend too, and adds Quick Share and AirDrop so phones can send without an extra app.

NearDrop

Quick Share receiver for macOS. MultiDrop covers Windows and Linux instead.

rquickshare

Quick Share for Linux and macOS, written in Rust. MultiDrop adds AirDrop, LocalSend, browser download and AirPlay in the same app, and runs on Windows.

OpenDrop

Open AirDrop implementation from the SEEMOO lab, a command-line research tool. MultiDrop uses omdrop-owl for the AWDL link and offers a desktop app.

Google Quick Share for Windows

Google's official app, Windows only and Quick Share only. MultiDrop is open source, needs no account, and also runs on Linux.

In short

Pick MultiDrop if you want one app on Windows or Linux that every phone can send to – iPhone, Android and Samsung – plus AirPlay to your TV.
