Quick Share for Windows, open source

MultiDrop puts your Windows PC into the Quick Share menu of Android and Samsung phones. No Google account, nothing installed on the phone.

Download for Windows ★ Source code on GitHub

How it compares

Google offers its own Quick Share app for Windows. MultiDrop is an open-source alternative that doesn't sign in anywhere and adds what Google's app doesn't: LocalSend for iPhones, a browser download for any phone, and AirPlay screen mirroring and audio to Apple TV, HomePod and Sonos.

Samsung phones

If a Samsung phone doesn't list the PC, scan the QR code tile in MultiDrop with its camera.

Tested with real phones

Quick Share is tested with real Android and Samsung Galaxy phones.

How to set it up

  1. Download MultiDrop-Setup.exe (or the portable MultiDrop.exe) and run it.
  2. Click Allow when Windows Firewall asks and make sure your Wi-Fi is set to Private.
  3. On the phone, tap Share → Quick Share and pick your PC.

Questions

Nothing arrives on Windows – what now?

Windows Firewall probably blocked MultiDrop. Allow it for private networks in Windows Security → Firewall → Allow an app.

Can I send from the PC to the phone?

Yes. Drop files on the phone in the MultiDrop window, or turn on Send to in the settings and right-click files in Explorer → Send to → MultiDrop.
