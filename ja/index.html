AirDrop、Quick Share、LocalSend、AirPlay をひとつのアプリで ― Windows と Linux に

近くのどのスマホの共有メニューにも PC が表示されます。iPhone は AirDrop、Android と Samsung は Quick Share、その他は LocalSend ― MultiDrop はそのすべてに同時に対応します。

Windows 版をダウンロード Linux にインストール ★ GitHub のソースコード

MultiDrop でできること

  • Windows と Linux で Quick Share / ニアバイシェア ― Android と Samsung のスマホが共有メニューから PC に送信、アプリ不要
  • Linux で AirDrop ― iPhone、iPad、Mac と送受信（対応 Wi-Fi カードが必要）
  • iPhone から Windows へ ― 無料の LocalSend アプリか、ブラウザで QR コードを読み取るだけ
  • AirPlay ― Windows や Linux の画面を Apple TV にミラーリング、PC の音を HomePod や Sonos で再生
  • プライベート ― Wi-Fi 上のデバイス同士で直接、暗号化、サーバーもアカウントも不要

Ubuntu と Debian

curl -fsSL https://digitaldanis.github.io/multidrop/multidrop-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/multidrop-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/multidrop-archive-keyring.gpg] https://digitaldanis.github.io/multidrop stable main" \
  | sudo tee /etc/apt/sources.list.d/multidrop.list
sudo apt update && sudo apt install multidrop

よくある質問

Windows で AirDrop は使えますか？

Apple の AirDrop 用無線（AWDL）は Windows の Wi-Fi ドライバーでは動きません。MultiDrop がそれ以外をカバーします。iPhone は LocalSend かブラウザの QR コードで、Android と Samsung は Quick Share で送れ、さらに AirPlay の画面ミラーリングも使えます。

Linux で AirDrop は使えますか？

はい。Wi-Fi カードが対応していれば（例：MediaTek MT7925）、MultiDrop は Linux で iPhone、iPad、Mac と AirDrop で送受信できます。

iPhone から PC へケーブルなしでファイルを送るには？

PC で MultiDrop を起動し、iPhone の無料アプリ LocalSend から送るか、ブラウザダウンロードの QR コードをカメラで読み取ります。

PC で Quick Share は使えますか？

はい。Windows と Linux で、MultiDrop は Android と Samsung の Quick Share メニューに表示されます。Google アカウントは不要です。

MultiDrop は無料でプライベートですか？

はい。オープンソース（GPL-3.0）で、サーバーもアカウントもなく、ファイルはデバイス間で直接やり取りされます。

AirDrop と AirPlay は Apple Inc. の、Quick Share は Google LLC と Samsung Electronics の商標です。MultiDrop は独立したオープンソースプロジェクトです。
